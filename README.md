# Personal Code Agents

A small, traceable collection of Codex agents and research skills for retrieval, model evaluation, multimodal research, data pipelines and scientific writing.

## Import baseline

This first revision preserves the selected upstream packages unchanged. It is a provenance checkpoint, **not a recommended installation**: some upstream defaults require adaptation. The next commit records those adaptations separately.

`provenance.json` identifies the source repository, exact upstream revision, source path and retained license for every imported agent and skill. Upstream files were copied directly, including supporting resources; no upstream installers were run.

The source catalogs are reviewed separately from installation. This repository is not automatically connected to any local or remote Codex profile.

## Contents

- `agents/`: selected native Codex TOML agent definitions.
- `skills/`: selected skill packages, with their supporting resources.
- `licenses/`: original upstream license texts. Package-specific notices remain in place.
- `provenance.json`: import mapping for updates and comparisons.

Imported material remains under its respective upstream license. Do not assume a single license covers all upstream catalogs or every nested asset.
